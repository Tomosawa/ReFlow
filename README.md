# ReFlow 智能位号

嘉立创EDA / EasyEDA 专业版原理图位号智能重分配扩展

<img src="./images/ScreenShot.png" alt="ReFlow 智能位号 截图" width="480" />

## 简介

**ReFlow 智能位号** 能够读懂你的电路逻辑，将原理图中电气连接在一起的元器件自动识别为一个个功能模块（图块），并为每个图块内的元器件分配连续的位号，让设计井然有序。

传统方式按位置逐一编号，导致同一功能模块的元器件位号散落各处。ReFlow 通过并查集算法分析导线连通性，确保关联元器件的位号（R/C/U 等）连续排列，大幅提升原理图的可读性和可维护性。

## 功能特性

### 三种编号模式

| 模式 | 示例 | 说明 |
|------|------|------|
| 跨页连续编号 | R1, R2, R3... | 所有页面连续编号 |
| 每页独立编号 | R101, R201 | R101=第1页R01，R201=第2页R01 |
| 每块独立编号 | R101, R201 | R101=第1块R01，R201=第2块R01，按连通模块编号 |

### 分配范围

- **所有页面** — 从 P1 开始按页面顺序依次分配（默认）
- **当前页面** — 仅重新分配当前打开的页面

### 起始编号

- **自动** — 所有页面模式下从 1 开始；当前页面模式下从系统已有最大编号 +1 开始
- **自定义** — 指定起始编号

### 已有位号处理（当前页面模式）

- **跳过已有** — 自动跳过其他页面已使用的编号（默认）
- **覆盖已有** — 强制分配，其他页面冲突位号变为未分配状态
- **全部清除** — 不考虑其他页面，直接分配

### 锁定元器件

输入或通过「从选择获取」按钮自动填写需要保留位号的元器件，其他编号自动绕过它们。

### 其他

- **撤销** — 一键恢复分配前的位号
- **多语言** — 支持中文 / English 界面切换
- **实时日志** — 显示分配进度和位号变更报告

## 使用

1. 打开原理图页面
2. 菜单 → **ReFlow 智能位号** → **分配位号...**
3. 在界面中选择编号模式和处理选项
4. 点击「开始分配」
