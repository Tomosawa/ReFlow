# ReFlow 智能位號

嘉立創EDA / EasyEDA 專業版原理圖位號智能重分配擴展

![Screenshot](./images/ScreenShot.png)

## 簡介

**ReFlow 智能位號** 能夠讀懂你的電路邏輯，將原理圖中電氣連接在一起的元器件自動識別為一個個功能模組（圖塊），並為每個圖塊內的元器件分配連續的位號，讓設計井然有序。

傳統方式按位置逐一編號，導致同一功能模組的元器件位號散落各處。ReFlow 透過並查集演算法分析導線連通性，確保關聯元器件的位號（R/C/U 等）連續排列，大幅提升原理圖的可讀性和可維護性。

## 功能特性

### 三種編號模式

| 模式 | 範例 | 說明 |
|------|------|------|
| 跨頁連續編號 | R1, R2, R3... | 所有頁面連續編號 |
| 每頁獨立編號 | R101, R201 | R101=第1頁R01，R201=第2頁R01 |
| 每塊獨立編號 | R101, R201 | R101=第1塊R01，R201=第2塊R01，按連通模組編號 |

### 分配範圍

- **所有頁面** — 從 P1 開始按頁面順序依次分配（預設）
- **當前頁面** — 僅重新分配當前開啟的頁面

### 起始編號

- **自動** — 所有頁面模式下從 1 開始；當前頁面模式下從系統已有最大編號 +1 開始
- **自訂** — 指定起始編號

### 已有位號處理（當前頁面模式）

- **跳過已有** — 自動跳過其他頁面已使用的編號（預設）
- **覆蓋已有** — 強制分配，其他頁面衝突位號變為未分配狀態
- **全部清除** — 不考慮其他頁面，直接分配

### 鎖定元器件

輸入或透過「從選擇獲取」按鈕自動填寫需要保留位號的元器件，其他編號自動繞過它們。

### 其他

- **撤銷** — 一鍵恢復分配前的位號
- **多語言** — 支援中文 / English 介面切換
- **實時日誌** — 顯示分配進度和位號變更報告

## 使用

1. 開啟原理圖頁面
2. 選單 → **ReFlow 智能位號** → **分配位號...**
3. 在介面中選擇編號模式和處理選項
4. 點擊「開始分配」
