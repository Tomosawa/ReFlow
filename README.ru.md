# ReFlow Smart Designator

Интеллектуальное расширение переназначения позиционных обозначений схем для JLCEDA / EasyEDA Pro

<img src="./images/ScreenShot.png" alt="ReFlow Smart Designator Скриншот" width="480" />

## Обзор

**ReFlow Smart Designator** понимает логику вашей схемы. Он автоматически определяет электрически соединённые компоненты как функциональные модули (кластеры) и назначает последовательные позиционные обозначения внутри каждого кластера, сохраняя схему упорядоченной и читаемой.

Традиционная последовательная нумерация разбрасывает связанные компоненты по всему диапазону обозначений. ReFlow использует алгоритм Union-Find для анализа связности проводников, гарантируя, что компоненты одного функционального блока получают последовательные обозначения (R/C/U и т.д.), что значительно повышает читаемость и поддерживаемость схемы.

## Возможности

### Три режима нумерации

| Режим | Пример | Описание |
|-------|--------|----------|
| Непрерывная | R1, R2, R3... | Последовательная через все страницы |
| По страницам | R101, R201 | R101 = страница 1 R01, R201 = страница 2 R01 |
| По блокам | R101, R201 | R101 = блок 1 R01, R201 = блок 2 R01, по подключённым модулям |

### Область действия

- **Все страницы** — Назначение начиная с P1 по порядку страниц (по умолчанию)
- **Текущая страница** — Переназначение только открытой страницы

### Начальный номер

- **Авто** — В режиме «Все страницы» с 1; в режиме «Текущая страница» с максимального существующего + 1
- **Пользовательский** — Указать начальный номер

### Обработка существующих обозначений (режим текущей страницы)

- **Пропускать** — Автоматически пропускать номера, занятые на других страницах (по умолчанию)
- **Перезаписывать** — Принудительное назначение; конфликтующие обозначения на других страницах становятся неназначенными
- **Очистить все** — Назначать без учёта других страниц

### Блокировка компонентов

Введите или автоматически заполните через кнопку «Из выделенного» компоненты, обозначения которых нужно сохранить. Остальные номера обходят их.

### Прочее

- **Отмена** — Возврат к предыдущим обозначениям одним кликом
- **Мультиязычность** — Поддержка интерфейса 中文 / English
- **Живой журнал** — Отображение прогресса и отчёта об изменениях обозначений

## Использование

1. Откройте страницу схемы
2. Меню → **ReFlow Smart Designator** → **Переназначить...**
3. Выберите режим нумерации и параметры обработки в интерфейсе
4. Нажмите «Начать»
